# 0.3.5 实现清单与限制

## 本次 0.3.5 修复

- 先保存完整副本，再移开符合完整程序封套的旧草稿；内容变化、保存失败或普通草稿均不清空。
- 设置提供旧稿查看和“恢复到原输入框（不发送）”；拒绝覆盖内容、改变地址或打断运行中的任务。
- 当前初始任务因遗留草稿暂停时可以自动继续；旧数学题、用户主动暂停和未知发送保持原状态。
- 运行中的新请求会阻止缺少请求归属的旧队列派发。
- v7 持久化草稿副本、阶段、尝试次数与审计；恢复副本与消息记录明确分开，不计作模型回复或共识。

## 0.3.4 修复

- 聊天发送时自动启动任务专用网页并检查，不再要求手动检测或预先存在回答样例；四个 DOM 平台共用可恢复的 prepareInitial 流程。
- 既有个人标签不作为新题的写入目标。专用页如恢复旧对话，程序自动新建聊天；非首页的零匹配结果不直接视为可发送的空白会话。
- 添加成员、发送、恢复时在用户操作入口申请首次网站访问权限；已有授权不会要求重复人工授予。未授权前禁止任务创建网站标签。
- 加载中的页面自动等待复查，60 秒启动/队列准备期限、下一检查时间及次数持久化；大脑路由同样等待，服务重启可继续，期限耗尽后明确暂停。
- 初始可尝试发送与已验证读取/完成能力严格分开；读不到真实回复仍不造回答、不宣布完成。
- 新增从聊天输入框直接 Enter，四个空白平台完整接收自然语言回复的受控浏览器场景；没有手动能力检查。

## 0.3.3 修复

- 修正 ResizeObserver 补丁初始化顺序，保证组件库的共享观察器也使用逐帧批处理；保留各观察目标的最新条目，取消观察和销毁时清理回调。
- 移除对 ResizeObserver 错误的全局拦截，真实错误继续可见。
- 详情弹窗改为独立 ReportDialog 原生 dialog 组件，焦点落在可见关闭按钮，Escape/按钮/遮罩关闭后恢复原触发按钮；不使用带 aria-hidden 的焦点占位元素。
- 新增侧边栏窄宽度、多次缩放、下拉键盘操作、确认气泡和详情弹窗焦点回归。

## 0.3.2 修复

- 唯一点名开头的提问可直接发送，即使只配置了一名讨论成员；重名或歧义不会转给全员。
- 点名聊天发送当前原话，普通文本回复直接落库，不强制 JSON、不合成模型观点。共识讨论协议保留。
- 新问题暂停旧队列/路由，保留历史与未知发送凭据。持久化当前请求归属，旧路由不能创建旧题，重启不自动恢复旧题。
- v6 升级先暂停遗留活动任务；旧草稿保留，新题使用独立可归属的专用会话。
- 输入框允许在上一题暂停或等待中发起新问题；当前路由等待时不显示旧题的快捷恢复按钮。历史任务仍在设置中管理。

## 0.3.1 修复

- 大脑请求采用持久化阶段队列，支持恢复、取消、确认丢失核对、一次协议纠错和真实错误展示；命令不阻塞两分钟。
- 每个大脑问题具有独立会话归属，修复请求保留该题归属；原始用户问题不被路由改写覆盖。
- 点名目标缺失、重名或歧义时保留错误，不扩大到其他成员；角色切换/删除保护未完成任务。
- 点名任务独立结束和报告，不冒充共识。讨论共识与独立证据政策显式保存在任务中，矛盾证据始终阻断。
- 独立处理回复事务，协议错误不会 abort 外层队列；具体失败原因持久化，纠错携带当前实体与参与者身份。
- 首次使用专用页，只有已结束且交付完成的页可复用；未知草稿不自动清除。缓存的完整回复可脱离已关闭网页继续处理。
- 当前上下文剔除旧版本立场；历史窗口不删除原文，必需内容不截断。用户发送失败保留输入；已结束报告自动更新。
- 设置中可展开当前任务的争议与证据，沿用本地文档核验和算式工具。

## 保留的网页适配能力

- 未发送且无历史交付记录的会话标签页关闭后自动重建，保存恢复审计；已有发送记录仍不会新会话重发。
- Gemini 已确认的空白首页可以开始首轮，读取和完成能力保持待验证。新对话切换保持前台以完成 SPA 渲染。
- 富文本按逻辑段落校验与写入，保留空行、缩进；完全匹配本请求全文和标记的草稿可恢复，其他草稿不覆盖。

- 根据真实页面 DOM 适配 DeepSeek 无可访问名称的聊天加号图标；限定页头、平台和唯一可见匹配，避免点击相邻分享控件。
- 独立 SessionPreparer：新对话控件按可访问名称识别，持久化切换请求、最多 30 秒分步等待与超时原因；切换过程不消耗发送重试或重复点击。
- 任务中可查看专用会话准备诊断，失败详情显示参与者名称；清空专用页后不再要求另留样例页才能继续初始尝试。
- DeepSeek 已确认空白首页可尝试首轮，严格区分“首条回复待验证”和已具备读取/完成能力。
- 已发请求的只读核对和轮询不再要求生成已经结束；已发送的旧队列可继续恢复，不重置成新请求。
- 确认丢失时最多五次只读核对，跨 DOM 节点识别标记；持续未知暂停。成功交付后清除旧 lastError，审计历史保留。
- ChatGPT 新版编辑器、发言标题回复定位、有明确结束边界的 DOM Range 提取及 display: contents；不把整个对话区当作模型回复。
- 页面诊断显示真实匹配选择器、回复数量和错误原因；失败恢复持久化最新原因和明细。
- 四个平台的网页 DOM 适配器：DeepSeek、豆包、ChatGPT、Gemini，具有编译期独立选择器配置。
- Chrome optional_host_permissions 逐网站申请，ISOLATED 世界 executeScript，只读取/操作页面 DOM，无 Cookie 或应用内部状态读取。
- 根据输入框、可读取回复、完成操作栏、登录和阻断提示计算页面就绪状态。条款信息保留为参考，不作为硬编码停止开关。
- 每任务/成员专用会话标签绑定；新会话检查，必要时点击明确的新对话按钮；不覆盖草稿，不向恢复的旧对话直接发送。
- textarea 原生 setter/input 事件、contenteditable 编辑与同步、发送按钮或 Enter；确认请求标记真的出现在用户消息区域后才认定提交成功。
- 等待请求之后的助手回复、生成停止、完成操作栏以及至少两次观察和 4 秒稳定文本，再保存完整响应。
- 网页发送准备记录先持久化；发送确认丢失时核对页面标记，不重复提交；记录归属和标签页校验。
- “保存并启动”，侧边栏 3 秒驱动后台短调度，关闭后由 alarm 继续；富文本发送可能短暂自动激活专用标签后恢复。
- IndexedDB v3 增加 browser_sessions 和 browser_deliveries，v4 增加 chat_notices，v5 增加 brain_requests，JSON 报告包含这些来源记录。

## 保留的本地核心功能

严格 TypeScript、Vue/Naive UI/Pinia、参与者管理、不可变原始问题、持久化任务状态机、幂等队列、有限安全重试、独立回答、交叉审查、事件驱动争议调度、版本化结论、独立立场、重大争议解决规则、逐结论全体认可、条件证据与事实隔离、按任务设置要求连续稳定共识（聊天入口保留当前的一轮设置，手动任务默认两轮）、最大轮数、无进展终止、Markdown/HTML/JSON 报告和数据删除。
