## 0.3.5 新增验证

- 十二个草稿核心场景：历史协议完整备份后只发当前问候；普通/引用/追加内容保护；保存失败不清空；对比前发生修改不替换；当前 DRAFT_PRESENT 在重启后继续；显式恢复不发送、非空不覆盖；完整格式与单个标记区分；已保存的旧普通请求全量核对；用户主动暂停不自动继续；旧路由暂停时保留 waiting 恢复阶段和原发送凭据。
- 没有当前请求归属的旧活动任务，在存在新前台请求时不能派发。
- 两项真实 DOM 编辑器回归（textarea/ChatGPT 富文本）：捕获完整文字，后来编辑拒绝清理，完整匹配才清空，备份填回不提交，地址不同拒绝恢复。富文本的空行以实际 DOM 读数为准，保存和恢复不丢失该读数。
- 生产扩展受控场景重现已观察的 0.3.4 状态：当前“小光头在吗”因 DRAFT_PRESENT 暂停，输入框含同一历史数学请求标记，旧数学任务仍暂停。自动 tick 后旧稿已完整保存，页面只提交当前问候，当前任务完成；设置可查看并填回备份，用户消息数量仍为一条。
- 原始证据 results/stale-draft.json 明确 fixtureOnly=true、oldPromptSent=false、archiveRestoredWithoutSending=true。本次真实账号没有测试发送。

## 0.3.4 新增验证

- 十一个自动启动集成场景：四平台无历史回答/无标签自动首发、加载时持久化等待与服务重启续行、未知旧对话自动新建聊天、加载超时如实暂停、未授权前不导航、大脑等待、已排队页面加载后只发送一次、网页地址不变但已清空的会话不会重复新建。
- 网站授权函数仅请求所配置支持平台的精确 origin，去重并如实返回拒绝；BrowserPort 验证未授权不创建标签、准备中的检查可前台渲染，人工检测仍被动。
- 新增生产扩展四平台浏览器场景：成员刚添加且没有 check，空白页没有回答或完成操作栏，直接从聊天输入框 Enter，未点能力检查，自动准备/提交/读取并完成四条自然语言点名回复。DeepSeek 和 ChatGPT 欢迎文案替换以验证不依赖固定欢迎词。
- 真实 Chrome 首次权限弹窗未在此测试中操作：新链路使用测试 manifest 预授权与预建标签；界面配置/焦点测试仅桩替换交互权限申请，后台真实 host access 仍然缺失，验证其 SITE_PERMISSION_REQUIRED 暂停。不能把这些测试写成真实授权交互已验收。
- 首次完整复核发现两项旧测试在网页地址不变时重复执行新建命令；调整为只点击一次、后续只读观察，并加入持久化清空证据的集成回归。最终完整 npm run verify 在获准隔离环境重新执行。原始结果：automatic-start.json、unit-tests.json、coverage.json、compliance.json、playwright-results.json。

## 保留的 0.3.2 回归

- 原数学任务已经排队但尚未提交时，发送“光头强在吗”：旧题持久化暂停，新题只发送本次原话；多次调度及服务重启不会派发旧题，只有明确恢复旧题才允许继续。
- 未完成的大脑路由被新点名问题替代，旧路由保留且不再发送；明确点名不必等待大脑重新解释。
- 持久化请求归属不匹配时，即使旧任务被错误改回运行状态，调度与重启恢复也会暂停它。
- 错误的恢复 ID 不改变当前任务归属、不暂停有效请求。
- v5 升级 v6 暂停遗留活动讨论和路由，保留队列 sending 状态、发送凭据及原始消息。
- direct 提示无论携带什么历史路由上下文都只返回本题原话；普通自然语言回复记为 not_applicable，不生成结构化观点、结论或假共识。报告保留全文。
- 生产扩展在隔离 DOM 网站中完成两次独立的大脑路由，再执行一次“光头强在吗”直接点名；检查实际用户消息区域不包含评审协议，数据库保存自然语言原文、生成点名报告。
- 界面在参与者尚未通过页面检测、旧题暂停时仍允许输入新问题，真正发送由后台能力门检查；未就绪如实暂停，不编造回复。

## 验证边界

所有模型回复都是 tests 内明确标记的受控测试内容；生产产物静态检查不含这些回复。测试浏览器使用临时配置，不连接个人 Chrome 或个人模型账号。需要授予 host access 的受控链路使用测试 manifest 副本与预建隔离页；不覆盖真实网站权限弹窗、真实网站导航与真实模型回答。

此前只读核对了真实侧边栏和输入框；没有恢复用户旧数学题、没有发送消息，也没有手动清理真实草稿。新恢复链路在隔离网页测试，不能声称用户当前网页已更新或已被清空。浏览器测试通过也不等于四个平台真实账号的无人值守全流程通过。逐平台实际状态见 PLATFORM-VERIFICATION.md。未做大量历史数据性能压测、自动联网事实核验或备份导入。
