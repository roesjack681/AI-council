# AI Council 0.3.5

通过已登录的 AI 网页账号组成多模型聊天室的 Chrome MV3 扩展，无需模型 API 或 API Key，任务与讨论数据保存在本地。

## 本版内容

- 聊天入口自动准备专用网页、检查输入状态并发送问题，无需先人工做能力检查。
- 支持 ChatGPT、DeepSeek、Gemini、豆包的网页 DOM 适配器。
- 成员名称与头像可自定义；支持点名自然语言问答和可选大脑路由。
- 多成员独立回答、交叉审查、争议处理、版本化结论与共识判断。
- 持久化队列、任务归属与恢复，结果未知时先核对，避免盲目重发。
- 旧程序草稿先完整备份，再核对全文移开；普通草稿保持保护，备份恢复不触发发送。
- 导出 Markdown、HTML、完整 JSON 报告。

## 安装

1. 下载 `ai-council-0.3.5.zip` 并解压。
2. 在 Chrome 打开 `chrome://extensions`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。
4. 打开侧边栏，在设置中确认隐私提示并添加成员，允许首次网站访问权限后即可提问。

已有用户更新原扩展目录并重新加载即可，数据保留。网站登录或验证码需要本人完成。

严格构建、166 项单元/集成测试、34 项隔离浏览器场景及静态边界检查通过。具体证据见仓库测试报告。

用户提供的截图已展示点名问候的实际回复；四个平台真实账号的完整多轮讨论和无人值守共识流程尚未全部验收。浏览器回归使用受控网页，不代表真实平台全流程验收。网站更新可能影响页面匹配，无法确认时会保留任务并说明原因。
